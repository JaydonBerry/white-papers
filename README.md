# white-papers
A collection of generalized context for use with AI-assisted tools and as learning material to upskill junior or mid-level developers.

## Format
Papers use an RFC-style Markdown layout with a standardized YAML frontmatter header, making the repo portable across GitHub Copilot, Obsidian, Logseq, and vector databases.

- Template: [`templates/WHITE-PAPER-TEMPLATE.md`](templates/WHITE-PAPER-TEMPLATE.md)
- Format spec: [`papers/WP-0001-white-paper-format.md`](papers/WP-0001-white-paper-format.md)
