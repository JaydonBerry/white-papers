# white-papers
A collection of White Papers written during my experience as a Senior Software Developer.

My roles and responsibilities extended that role into aspects of Team Leadership and Software Architecture.
The goal of the repository is to crystalize my experiences and make it transferable if applicable.

## Format
Papers use an RFC-style Markdown layout with a standardized YAML frontmatter header, making the repo portable across ADO Wiki, Github CoPilot and many other AI assisted tools or Markdown repositories.

- Template: [`templates/WHITE-PAPER-TEMPLATE.md`](templates/WHITE-PAPER-TEMPLATE.md)
- Format spec: [`papers/WP-0001-white-paper-format.md`](papers/WP-0001-white-paper-format.md)
